## 1. 审核说明

### 1.1 坐标目标

- `main-entrance`：建筑、场馆和旧址采用观众主要入口或最接近入口的公开地图点位。
- `site-center`：桥梁、城址、公园和纪念地等空间型地点采用整体空间中心。
- 香山革命纪念地按项目负责人已核定的规则，以香山公园内八处中共中央北京香山革命纪念地旧址的整体中心为锚点，不采用香山革命纪念馆或香山公园中心。

### 1.2 候选来源

正式名称、地址和空间范围优先采用北京市人民政府、北京市文物局、北京市公园管理中心、北京市园林绿化局及清华大学等权威来源。经纬度候选来自高德地理编码或高德 POI；香山革命纪念地中心为依据高德可定位旧址点位边界计算的人工落点候选。

### 1.3 核定结果填写方式

审核人可将每项标记为：

- `通过`：候选点符合既定定位目标，可晋级为 `verified`；
- `调整`：地点身份正确，但应移动到审核人指定位置；
- `退回`：候选地点身份或空间范围有误，需要重新搜寻。

每个通过审核的地点将写入：

```ts
{
  status: "verified",
  lat: number,
  lng: number,
  crs: "GCJ-02",
  target: "main-entrance" | "site-center",
  precision: "verified-poi" | "manual-pin",
  sourceId: "source-amap-geocoder",
  verifiedAt: "YYYY-MM-DD",
  verifiedBy: "project-owner"
}
```

其中入口或整体 POI 可使用 `verified-poi`；经过人工移动、空间中心计算或看图落点的坐标使用 `manual-pin`。
