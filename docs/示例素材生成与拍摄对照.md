# 示例素材生成与拍摄对照

## 1. 使用原则

### 1.1 文件约定

13 张示意图均由 OpenAI 图片生成能力创建，再统一裁切为页面记录中的目标尺寸。每张图使用 `/media/{id}.webp` 固定路径，并在像素中写入蓝绿边框、“AI 生成示意素材”、素材 ID、用途与尺寸。

正式拍摄完成后，以本清单的画面结构为检索参照，选出相似素材并通过转换脚本覆盖同名文件。正式素材仍需完成署名、日期、人物同意和授权记录核验。

### 1.2 统一生成约束

统一提示词要求当代中国大学生社会实践纪实摄影或可信成果预览，采用自然光、克制的电影化调色和非摆拍构图；画面不生成可读标牌、校徽、水印、旗帜、路线曲线、圆点或历史情景再现。

## 2. 实践与首页素材

### 2.1 `field-01` 现场寻访

生成提示：4 名学生在讲解员带领下进入北京革命史纪念场馆，携带相机与笔记本，中远景、阴天柔光、4:3。

实拍匹配：地点入口或场馆身份清楚，队员处于进入、观察或记录动作中。

### 2.2 `field-02` 深度访谈

生成提示：学生在展陈空间采访年长讲解员，录音设备、手写记录和人物关系均可见，4:3。

实拍匹配：优先选择受访者自然表达、采访者倾听且记录动作清楚的画面。

### 2.3 `field-03` 社区传播

生成提示：青年在社区活动室向居民展示历史照片并讲解，画面同时包含不同年龄受众的反应，4:3。

实拍匹配：讲解者、传播材料与参与者反馈应同时进入画面。

### 2.4 `field-04` 数字采集

生成提示：相机、三脚架和录音设备正在采集历史图像资料，俯侧视角突出设备与对象关系，4:3。

实拍匹配：优先选择“设备正在工作”的动作画面，不使用单纯器材摆拍。

### 2.5 `field-05` 青年同行

生成提示：5 名学生携带相机和地图走向纪念场馆，人物背向镜头，建筑与行动方向形成首屏纵深。现有生成原图直接裁切为 1536×864 的 16:9 示例画幅，不进行分辨率放大。

实拍匹配：3 至 6 名队员共同进入现场，保留可供首屏标题使用的安静区域。

## 3. 数字成果素材

### 3.1 `outcome-01` 数字线上展厅

生成提示：黑、红、灰的数字展厅界面，包含路线地图、三段路线索引、地点档案与证据缩略图，16:10。

正式匹配：使用真实线上展厅的完整界面截图，确保路线、地点和档案关系清楚。

### 3.2 `outcome-02` 数字档案

生成提示：象牙白与深红的单条数字档案界面，包含地点图像、坐标日期、来源、实践记录和关联素材，16:10。

正式匹配：选择字段最完整的一条真实档案记录，隐藏不宜公开的信息。

### 3.3 `outcome-03` 主题微电影

生成提示：学生携带相机穿行于展陈空间，暗部、反射和暖色出口构成纪实电影封面，16:9。

正式匹配：从成片中选择具有行动方向、人物关系和标题安全区的关键帧。

### 3.4 `outcome-04` 实践调研报告

生成提示：深红、黑与象牙白的报告封面及内页展开，搭配笔记、存储卡和地图，3:2。

正式匹配：拍摄或导出真实报告封面与代表性内页，版面文字需可辨且内容已核验。

## 4. 传承与影响素材

### 4.1 `legacy-01` 首屏人物

生成提示：青年学生在纪念场馆内手持笔记本和录音设备的环境肖像，自然视线、柔和侧光、4:5。

实拍匹配：人物、事件背景和原话记录能够相互对应，并已取得公开同意。

### 4.2 `legacy-02` 社区行动

生成提示：学生与老年居民围桌交流历史照片，形成明确对话和现场反馈，16:9。

实拍匹配：同时呈现青年行动与社区参与者反应，避免纯合影。

### 4.3 `legacy-03` 结果证据

生成提示：笔记本电脑中的数字档案界面与课程材料、反馈单、入库卡和照片共同组成证据静物，3:2。

实拍匹配：优先使用可核验的课程使用、资料入库、展映或反馈记录。

### 4.4 `legacy-04` 继续行进

生成提示：4 至 5 名学生在黄昏离开纪念场馆并走向城市，背影、器材和开阔前方形成开放式结尾，16:9。

实拍匹配：团队离开或继续前行的自然动作，画面保留明确方向和足够环境信息。
